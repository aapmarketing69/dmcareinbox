# ประเมินค่าใช้จ่าย Server, Storage และ API (Cost Estimation)

> อ้างอิงอัตราแลกเปลี่ยนโดยประมาณ **1 USD ≈ 34–35 THB** (ราคาอาจเปลี่ยนแปลงตามผู้ให้บริการและแพ็กเกจปัจจุบัน)

---

## 1. ค่าใช้จ่ายฝั่ง Infrastructure (Server + Database + Media Storage)

แบ่งตามขนาดปริมาณแชทต่อวัน (รวมทุกร้าน LINE `a1–a5` + Facebook `b1–b5`):

| ระดับธุรกิจ | ปริมาณแชท / วัน | แอดมินพร้อมกัน | สเปกที่แนะนำ | ค่าใช้จ่ายรายเดือน (ประมาณ) |
| :--- | :--- | :--- | :--- | :--- |
| **Tier 1: Starter** | < 1,000 ข้อความ/วัน (~30k/เดือน) | 1–5 คน | • VPS 1 เครื่อง (2 vCPU, 4GB RAM) รัน App + Postgres + Redis (เช่น DigitalOcean / Hetzner / Vultr)<br>• Cloudflare R2 (ฟรี 10GB แรก, Egress ฟรี) | **~$10 – $24 / เดือน**<br>(**~350 – 850 บาท/เดือน**) |
| **Tier 2: Growth** | 1,000 – 10,000 ข้อความ/วัน (~300k/เดือน) | 5–25 คน | • App Server 2 vCPU / 4GB RAM (Railway / Render / DigitalOcean App Platform)<br>• Managed PostgreSQL (1–2GB RAM) + Managed Redis<br>• Cloudflare R2 (100GB รูป/ไฟล์) | **~$55 – $110 / เดือน**<br>(**~1,900 – 3,800 บาท/เดือน**) |
| **Tier 3: Scale / High Availability** | 50,000+ ข้อความ/วัน (1.5M+/เดือน) | 30–100+ คน | • App + Worker Autoscaling (2–4 instances บน AWS ECS / Cloud Run / GKE)<br>• Managed Postgres HA (Primary + Read Replica) + Redis Cluster<br>• S3/R2 + CloudFront CDN + Monitoring (Sentry/Datadog) | **~$250 – $550+ / เดือน**<br>(**~8,500 – 19,000+ บาท/เดือน**) |

### จุดประหยัดค่าใช้จ่ายที่สำคัญ
1. **ใช้ Cloudflare R2 แทน AWS S3 สำหรับเก็บรูปแชท:** รูปที่ลูกค้าส่งมา (สลิปโอนเงิน, รูปสินค้า) มีการเปิดดูซ้ำบ่อยมาก R2 **ไม่คิดค่า Egress (ค่า Bandwidth ขาออก)** ประหยัดได้มากเมื่อเทียบกับ S3
2. **เก็บ Webhook Payload ดิบแค่ 7–14 วัน:** ตั้ง Cron Job ลบ `raw_payload` ในตาราง `webhook_events` ที่เก่าเกินกำหนด เพื่อไม่ให้ Database บวม

## 2. ค่าใช้จ่ายฝั่ง Social Platform APIs (จุดที่คนมักลืมคำนวณ!)

### A. Facebook Messenger API (`b1–b5`)
- **ค่า API:** **ฟรี (0 บาท)** สำหรับการรับข้อความและตอบแชทลูกค้าภายใน 24 ชม. (และ Human Agent tag ภายใน 7 วัน)
- **ค่าใช้จ่ายแฝง:** ไม่มีค่าต่อข้อความ ยกเว้นถ้ามีการยิงโฆษณา Click-to-Messenger หรือใช้ Marketing Messages นอกกรอบ 24 ชม.

### B. LINE Messaging API (`a1–a5`) — คิดแยกต่อ LINE OA ทีละร้าน!
LINE คิดค่าใช้จ่ายตาม **แพ็กเกจรายเดือนของแต่ละ LINE OA** และนับเฉพาะข้อความประเภท **Push / Broadcast** (ข้อความที่ใช้ **Reply API** ตอบกลับภายใน ~1 นาที **ฟรีไม่หักโควตา!**)

| แพ็กเกจ LINE OA (ประเทศไทย) | ราคาต่อ 1 ร้าน / เดือน | โควตา Push/Broadcast ฟรี | หากมี 5 ร้าน (`a1–a5`) |
| :--- | :--- | :--- | :--- |
| **Free** | 0 บาท | 300 ข้อความ/เดือน | **0 บาท/เดือน** |
| **Basic** | ~1,200 บาท *(ไม่รวม VAT)* | 15,000 ข้อความ/เดือน | **~6,000 บาท/เดือน** |
| **Pro** | ~1,500 บาท *(ไม่รวม VAT)* | 35,000 ข้อความ/เดือน (เกินคิด ~0.04–0.08 บ./ข้อความ) | **~7,500 บาท/เดือน** |

> **เคล็ดลับลดค่าใช้จ่าย LINE Push API ให้ได้ 40–70%:**
> 1. ระบบของเราเก็บ `replyToken` ล่าสุดของลูกค้าไว้เสมอ — หากแอดมินตอบกลับภายใน ~50 วินาที ระบบจะใช้ **Reply API (ฟรี)** โดยอัตโนมัติ
> 2. หากแอดมินต้องการส่งข้อความหลายประโยคติดกัน (เช่น "สวัสดีครับ" + รูป + เลขบัญชี) ควรรวบส่งเป็น **1 API Call (สูงสุด 5 bubbles/messages ต่อ 1 request)** เพราะ LINE นับโควตาต่อ 1 การส่ง (หรือตามเงื่อนไขแพ็กเกจ) ลดการยิงซ้ำซ้อน
> 3. สำหรับร้าน `a1–a5` ที่มียอดแชทไม่เท่ากัน ไม่จำเป็นต้องซื้อแพ็กเกจเดียวกันทุกร้าน — ร้านที่แชทน้อยใช้ Free/Basic ร้านที่แชทเยอะใช้ Pro
